# Platform icons

Individual SVG brand marks from [Font Awesome Free 7.3.1](https://github.com/FortAwesome/Font-Awesome/tree/7.x/svgs/brands), by Fonticons, Inc.

The Font Awesome SVGs retain their original attribution and are licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). See [LICENSE-Font-Awesome.txt](./LICENSE-Font-Awesome.txt).

The Samsung Internet mark comes from [Browser Logos](https://github.com/alrra/browser-logos/tree/main/src/samsung-internet). Its planet paths are retained in a monochrome adaptation; the colored background and shadow were removed. Logos and trademarks belong to their respective owners; the collection's code license is included in [LICENSE-Browser-Logos.txt](./LICENSE-Browser-Logos.txt).

Analytics renders these local assets as CSS masks in the theme's accent color. No icon package or third-party runtime requests are required.

The shared mapping covers PeakURL's canonical browser and OS families, including iOS and iPadOS with the Apple mark and Android with its own mark. Uncommon browser and OS names returned by Matomo always receive a generic icon. Device categories match the parser's Desktop, Mobile, Tablet, TV, Console, and Unknown Device results.
