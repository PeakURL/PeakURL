PeakURL

v1.8.0

PeakURL is a self-hosted short link management and analytics platform with native Model Context Protocol (MCP) server integration.

License: MIT License
Runtime: PHP 8.3 or later
Database: MySQL 5.7+ or MariaDB 10.4+

Server Requirements

Verify that your web server meets these requirements before running the installation:

PHP Runtime

  • PHP 8.3 or later
  • Required extensions: pdo, pdo_mysql, mbstring, openssl, json, curl
  • memory_limit of 128MB or higher

Database

  • MySQL 5.7 or later, or MariaDB 10.4 or later
  • Default character set: utf8mb4
  • Full schema and table creation privileges

Web Server

  • Apache with mod_rewrite, Nginx, or equivalent
  • Allow directory index files (e.g., index.php)
  • Write permissions on the root directory to save config.php

Security & Transport

  • HTTPS enabled for production deployments
  • Required for secure cookies and OAuth 2.0 PKCE flows
  • Restrictive file permissions (e.g., 0640)

Installation

PeakURL automatically routes new deployments into its interactive configuration wizard:

  1. 1
    Upload and Extract

    Extract the release package into your web server document root or a supported subdirectory.

  2. 2
    Create Database

    Create a MySQL or MariaDB database and associated database user with all privileges.

  3. 3
    Open in Browser

    Navigate to your site URL in a web browser. PeakURL detects new installs and opens the configuration wizard.

  4. 4
    Database Configuration

    Enter your database host, name, username, password, and table prefix. PeakURL verifies the connection and writes config.php.

  5. 5
    Administrator Setup

    Provide your site title, administrator name, email address, and a secure password to complete installation.

  6. 6
    Access Dashboard

    Sign in with your administrator credentials to start creating links, managing roles, and connecting AI clients.

Deployment Tip: PeakURL automatically derives base paths and supports both site-root deployments (e.g., https://example.com/) and subdirectory installations (e.g., https://example.com/links/).

After Installation

Location Data (GeoIP)

Navigate to Settings → Location Data to download the local MaxMind GeoLite2 City database for geographic visitor analytics.

PeakURL MCP Server

Connect AI clients (Claude Desktop, ChatGPT, Cursor, Windsurf) via Settings → MCP Server using standard Streamable HTTP and OAuth 2.0 PKCE.

Background Automation

Configure a system cron job to run maintenance, link health checks, and webhook retries: * * * * * php /path/to/peakurl/index.php

Role Delegation

Use Users → Manage Roles to delegate specific administrative capabilities (including MCP server management) to Editors or custom roles.
